# Milestone 1 - Hello World

## Project Overview

This is my first project as part of the **YuvaIntern Frontend Development Internship**.

The project is a simple and responsive Hello World webpage developed using HTML, CSS, and JavaScript.

It demonstrates the basic concepts of frontend web development, including webpage structure, styling, and JavaScript interactivity.

## Technologies Used

- **HTML5** – Creates the structure of the webpage.
- **CSS3** – Provides styling, layout, and responsive design.
- **JavaScript** – Adds interactive functionality.

## Features

- Simple and clean user interface.
- Responsive webpage design.
- Interactive welcome button.
- Dynamic message displayed using JavaScript.
- Organized project structure.

## Project Structure

```text
hello-world/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser.

4. Click the **Click Me** button to see the JavaScript interaction.

You can also use the Live Server extension in VS Code.

## Learning Objectives

Through this project, I practiced:

1. Creating an HTML document.
2. Applying CSS styles.
3. Connecting external CSS and JavaScript files.
4. Using JavaScript DOM manipulation.
5. Handling click events.
6. Organizing a frontend project.
